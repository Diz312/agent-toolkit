# Scout 2026-11-14 (run 1)

First scout run. Proposing 5 additions: Context7 for live docs, the Superpowers dev-loop skills, and Anthropic's mcp-builder, webapp-testing and skill-creator. Graphify is on the watchlist as a commercially licensed alternative to GitNexus.

## Proposed

- **[grill-me + grilling](https://github.com/mattpocock/skills/tree/HEAD/skills/productivity)** (skill, context-engineering): Requested by the user. Instruction-only; grill-me is a manual trigger that calls grilling.
- **[context7](https://github.com/upstash/context7)** (mcp, agentic-app-dev, score 89): Most-used live-docs MCP; makes 'verify APIs before coding' automatic. Needs a free CONTEXT7_API_KEY.
- **[superpowers core dev skills (8)](https://github.com/obra/superpowers)** (skill, agentic-app-dev, score 90): Largest skills framework (317k stars, in 4 curated lists). Taking the 8 dev-loop skills only; skipping brainstorming (starts a local web server) and Superpowers-internal meta skills.
- **[mcp-builder](https://github.com/anthropics/skills/tree/HEAD/skills/mcp-builder)** (skill, agentic-app-dev, score 100): Official guide plus eval scripts for building MCP servers.
- **[webapp-testing](https://github.com/anthropics/skills/tree/HEAD/skills/webapp-testing)** (skill, agentic-app-dev, score 100): Official Playwright testing skill; closes the build-verify loop.
- **[skill-creator](https://github.com/anthropics/skills/tree/HEAD/skills/skill-creator)** (skill, context-engineering, score 100): Official; portable copy so Codex/Cursor/Antigravity get it too (Claude Code already has it via a plugin).

## Watchlist

- **[graphify](https://github.com/Graphify-Labs/graphify)** (mcp, agentic-app-dev, score 80): Apache-2.0 code knowledge graph (147k stars). Strong alternative to GitNexus, whose PolyForm Noncommercial license rules out work use. Compare on your monorepos before switching.
- **[codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)** (mcp, agentic-app-dev, score 83): MIT code-intelligence graph; overlaps GitNexus. Keep as a fallback.
- **[chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)** (mcp, agentic-app-dev, score 88): Official Chrome DevTools MCP for frontend debugging; candidate for next run (overlaps webapp-testing).
- **[github-mcp-server](https://github.com/github/github-mcp-server)** (mcp, agentic-app-dev, score 87): Official GitHub MCP; needs a PAT. gh CLI already covers most needs, so deferred.
- **[ida-pro-mcp](https://github.com/mrexodia/ida-pro-mcp)** (mcp, reverse-engineering, score 74): Popular IDA bridge; REA already wraps IDA/Ghidra/Hopper. Only worth it if you use IDA directly.
- **[leanrea](https://github.com/aicodeking/leanrea)** (skill, reverse-engineering, score 30): 8 KB CLI-only alternative to REA claiming lower cost; compare after you have used REA.
- **[agent-skills](https://github.com/addyosmani/agent-skills)** (skill, agentic-app-dev, score 80): Strong engineering skills; overlaps superpowers. Revisit after a week with superpowers.
- **[context-engineering skills](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering)** (skill, context-engineering, score 80): Focused context-engineering collection (MIT, 1 curated list); review individual skills next run.
- **[claude-mem](https://github.com/thedotmack/claude-mem)** (plugin, context-engineering, score 85): Popular persistent-memory plugin; captures all sessions, so review privacy and storage first.

## Rejected

- **[ECC](https://github.com/affaan-m/ECC)** (skill, agentic-app-dev, score 63): Sprawling harness overlay (skills, hooks, memory, settings) that overlaps superpowers and rewrites a lot of config.
- **[firecrawl](https://github.com/firecrawl/firecrawl)** (mcp, everyday-automation, score 58): AGPL and a hosted API key for web scraping; WebFetch covers current needs.
- **[n8n](https://github.com/n8n-io/n8n)** (skill, everyday-automation, score 58): A workflow platform, not a skill or MCP server.
