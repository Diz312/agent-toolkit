Proposing 4 additions for building agentic apps: Anthropic's agent-sdk-dev and claude-md-management plugins for Claude Code, and the tool-design and multi-agent-patterns skills. Two MCP version bumps (rea, Playwright MCP). All 14 pinned skills match upstream.

## Proposed

- **[agent-sdk-dev](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/agent-sdk-dev)** (plugin, claude-code, agentic-app-dev, score 88): Official. `/new-sdk-app` scaffolds a Claude Agent SDK app in Python or TypeScript and verifier agents check it. Commands and agents only, no hooks or MCP. It asks which tooling to use, so pick uv.
- **[claude-md-management](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/claude-md-management)** (plugin, claude-code, context-engineering, score 85): Official. Audits CLAUDE.md files against the code and `/revise-claude-md` captures session learnings. Shows diffs and edits only after approval.
- **[multi-agent-patterns](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering/tree/HEAD/skills/multi-agent-patterns)** (skill, agentic-app-dev, score 78): Supervisor/swarm/handoff design and when not to go multi-agent. MIT, 18k stars, 1 curated list (on the watchlist since run 1). skillshare audit: 4 LOW (external doc links), fine.
- **[tool-design](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering/tree/HEAD/skills/tool-design)** (skill, agentic-app-dev, score 77): Tool descriptions, schemas, naming and error design for agents; complements mcp-builder. Audit clean. Both skills ship an optional Python helper script that the agent may run; neither does network or subprocess calls.
