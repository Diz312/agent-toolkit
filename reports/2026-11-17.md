## Proposed

- **[chrome-devtools](https://github.com/ChromeDevTools/chrome-devtools-mcp)** (mcp, agentic-app-dev, score 72): Official Chrome DevTools team, Apache-2.0, 58k stars. Adds performance traces and network/console debugging that Playwright MCP lacks. Pinned `chrome-devtools-mcp@1.13.0` with `--no-usage-statistics --no-performance-crux` (both default on, sending data to Google) and `--isolated` (throwaway browser profile). Flags checked against the v1.13.0 source. No secrets.
- **[finishing-a-development-branch](https://github.com/obra/superpowers/tree/HEAD/skills/finishing-a-development-branch)** (skill, agentic-app-dev, score 84): Closes the installed using-git-worktrees loop: tests first, then a menu (merge, PR, keep, discard), and it refuses to force-push or merge on its own. Instruction-only; audit clean.
- **[tool-design](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering/tree/HEAD/skills/tool-design)** (skill, agentic-app-dev, score 78): How to write tool descriptions, schemas and error messages agents route on well. Complements mcp-builder. MIT; audit clean; ships a local Python helper with no network or subprocess calls.
- **[multi-agent-patterns](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering/tree/HEAD/skills/multi-agent-patterns)** (skill, agentic-app-dev, score 77): Supervisor, swarm and handoff patterns and when a single agent is better. Audit: 4 LOW (reference links).
- **[context-optimization](https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering/tree/HEAD/skills/context-optimization)** (skill, context-engineering, score 76): Context budgets, observation masking, cache-friendly prefixes and compaction for the apps you build. Audit clean.
