## Proposed

- **[fastmcp-server](https://github.com/PrefectHQ/fastmcp/tree/a514cf9604309490240bab2c7d6782c5f68d5c57/docs/.mintlify/skills/fastmcp-server)** (skill, agentic-app-dev, score 73): Comes from the FastMCP maintainers (28.7k stars, Apache-2.0, pushed today). It tells the agent to check the project's installed FastMCP version and read the matching docs (`gofastmcp.com/llms.txt`) before writing code. It then covers tools, resources and prompts, schemas from type annotations, and pagination and error results. This is the framework-specific half that the generic `mcp-builder` lacks, and it fits the uv/Python stack. It is instruction-only (one 5.6 KB SKILL.md), and skillshare audit reports 1 LOW finding: an external doc link.

## Watchlist (new)

- **[headroom](https://github.com/headroomlabs-ai/headroom/tree/HEAD/skills/headroom)** (skill, score 71): Adds `headroom-ai`'s `compress()` call to apps you build, to shrink tool outputs, logs and chat history before the LLM call. The skill audit is clean. However, the skill says "no network" while the package ships a telemetry beacon (`headroom/telemetry/beacon.py`) and depends on litellm. Confirm the opt-out before adding it.
- **[mcp-toolbox](https://github.com/googleapis/mcp-toolbox)** (mcp, official Google, score 78): A database MCP for Postgres, SQLite, BigQuery and more (v1.18.0). Each database needs its own `tools.yaml` and connection secrets, so it fits per-project config better than the global catalog.
